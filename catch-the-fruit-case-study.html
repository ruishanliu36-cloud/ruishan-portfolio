Catch the Fruit

A Python arcade game in which players move a character to catch falling fruit while avoiding missed attempts.

Python Collision detection Keyboard controls Game logic

Overview

The challenge

I wanted to build a simple arcade game that was easy to understand but still required timing, movement, and quick reactions.

The goal was to create a playable experience where users move the character with the keyboard and catch randomly falling fruit.

My role

What I programmed

  • Keyboard controls for player movement
  • Randomized fruit positions
  • Collision detection between the player and fruit
  • Score and missed-attempt tracking
  • Game reset and replay logic

Process

How I built it

01

Plan the game

I defined the main rules, player controls, scoring system, and conditions for winning or losing.

02

Build movement

I programmed keyboard input so the player could move across the screen while staying inside the game boundaries.

03

Add interactions

I created collision logic that detects when the player catches a fruit and updates the score.

04

Test and improve

I tested the controls and game speed, then adjusted the timing and reset behavior to make the game easier to play.

Challenge

What was difficult

One challenge was making collision detection feel accurate. The game needed to recognize when the fruit and player overlapped without counting a catch too early or too late.

I solved this by checking the positions and boundaries of both game objects before updating the score.

Reflection

What I learned

This project helped me understand how keyboard input, loops, conditions, coordinates, and collision detection work together in an interactive program.

In a future version, I would add difficulty levels, sound effects, different fruit types, animations, and a high-score system.
