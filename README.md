# Ruishan Portfolio

A responsive one-page portfolio built with plain HTML, CSS, and JavaScript.

## Open it in VS Code

1. Unzip the folder.
2. Open VS Code.
3. Choose **File → Open Folder** and select `ruishan-portfolio`.
4. Install the **Live Server** extension.
5. Right-click `index.html` and choose **Open with Live Server**.

No Node.js or npm is required.

## Replace the placeholder images

Put your images inside the `assets` folder using these exact names:

- `portrait.jpg`
- `art-1.jpg`
- `art-2.jpg`
- `art-3.jpg`
- `art-4.jpg`
- `Ruishan-Liu-Resume.pdf`

You may also change the file names inside `styles.css` and `index.html`.

## Update project links

In `index.html`, replace each `href="#"` with the correct Scratch, Replit, Figma, GitHub, or case-study link.

## Privacy note

The original public contact page showed a phone number. This redesign intentionally leaves the phone number out. Email and LinkedIn are usually enough for a student portfolio.
